### Sort products by price (low to high)

**Error:** AssertionError: expected first product price to be $7.99, got $9.99 — sort option appears not to apply on initial render.

**Screenshot:** `reports/screenshots/sort_failed_20260509_143245.png`

**Failing selector:** `.inventory_item_price`

**Analysis:**

**Root cause:** The `<select>` change event fires before the inventory list has re-rendered, so the assertion runs against the unsorted DOM. This is a real product bug, not a test issue — the visible price order does not match the selected sort option.

**Suggested fix in the test (defensive):** wait for the first `.inventory_item_price` text to change before asserting:

```python
await page.locator('.product_sort_container').select_option('lohi')
await expect(page.locator('.inventory_item_price').first).to_have_text('$7.99')
```

**Suggested fix in the app:** ensure the inventory store re-emits before the select change handler resolves, or render the sorted list synchronously.
